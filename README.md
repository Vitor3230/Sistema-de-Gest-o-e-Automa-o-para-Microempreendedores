# Sistema-de-Gest-o-e-Automa-o-para-Microempreendedores
Descrição: Planilha inteligente desenvolvida para automatizar o fluxo de caixa de um salão de beleza, tratando diferentes taxas de pagamento e fornecendo indicadores de desempenho.

Funcionalidades:

Cálculo automático de descontos (Pix/Débito) e acréscimos (Crédito).

Dashboard de status diário (Dias Positivos vs. Negativos).

Interface de agendamento com validação de dados.

Lógica Utilizada: Uso intensivo de funções IF, SUM, ARRAYFORMULA e Formatação Condicional.
